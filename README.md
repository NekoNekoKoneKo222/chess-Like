# CHESS LIKE — チェスライク

チェスとローグライクの戦闘を組み合わせた、Webブラウザで遊べる1人用戦略ゲームです。**15ステージ**、**32種類の漢字名の駒**、戦闘ごとの3択報酬、保存機能を実装しています。敵の配置も駒の性能もTXTで変更できます。

## 遊び方

1. 出陣する駒を最大8体選び、戦闘開始。王将は必須です。
2. 盤面で味方駒をクリック／タップし、移動可能なマスを選択します。敵のいるマスを選ぶと攻撃します。
3. ダメージは先に敵の**防御力**を減らし、余った分だけ**HP**を減らします。敵が生き残った場合、攻撃した駒は元のマスに留まります。
4. 全敵撃破で勝利。未所持の駒が3つ表示され、その中から1つ選んで仲間にできます。
5. 次のステージでは自軍のHP・防御力が全回復。王将が倒れると遠征失敗で第1局からやり直しです。15局クリアが目標です。

### 特殊駒

| 駒 | 種類 | 効果 |
| --- | --- | --- |
| 爆弾魔 | ダメージ＋効果 | 攻撃が命中し生存した敵に爆弾を付けます。爆弾を付けられた駒は3回の自軍手番の間に**設置した爆弾魔を攻撃**すれば解除。解除されなければ近くの駒（敵味方問わずランダム1体）が効果によって破壊されます。周囲に駒がなければ空振り。 |
| 寄生虫 | ダメージ＋効果 | 攻撃で倒した駒をHP半分・防御力0の状態で自軍へ転向させます。ただし効果無効の駒は普通に破壊されます。 |
| 敵 | 移動効果 | 移動すると接近阻止を発動。相手はその駒の隣接マスに**通常移動で近づけなくなります**。隣からの攻撃や駒を直接狙う攻撃は可能です。 |
| 王将・幽霊・聖騎士 | 効果無効 | 爆弾、寄生、処刑などの「効果攻撃」を無効化します。通常ダメージは防げません。 |
| 処刑人 | ダメージ＋効果 | 通常ダメージの後、HP2以下で残った相手を破壊します。効果無効の駒は破壊されません。 |

レア度は**コモン（白）／レア（青）／レジェンダリー（黄）**。報酬のレア度抽選比率は70:25:5です。該当レア度に未所持の駒がない場合は、残りのレア度から選びます。

## ローカルで起動

サーバー機能やデータベースは不要。`site` ディレクトリを静的Web配信すれば動作します。例：

```bash
python3 -m http.server 8080 -d site
```

ブラウザで `http://localhost:8080` を開きます。`index.html` をファイルから直接開くとTXTを取得できない場合があります。

テスト：

```bash
npm test
npm run check
```

## 敵駒・ステージの編集（TXTだけでOK）

[`site/stages.txt`](site/stages.txt) を編集してください。プログラムを書き換える必要はありません。敵駒配置は毎回固定で、ランダム生成されません。

```txt
@1|開戦|はじめての敵陣。
歩兵,3,1
衛兵,4,1

@2|挟撃|斜めから迫る軍勢。
騎士,2,1
僧正,5,0
```

- `@番号|ステージ名|説明` の行でステージを定義（1〜15を順番に記入）。
- `駒名,x,y` で敵の種類と位置を指定。左上が `0,0`、右下が `7,7` です。
- 敵駒は上半分 `y=0〜3` に配置。重複マスは不可。各ステージ最低1体が必要。
- 使用可能な駒名と能力は [`site/data.js`](site/data.js) にあります。
- ゲーム画面にはステージの編集機能はありません。公開内容の変更はGitHub上のTXTから行ってください。

## 駒の性能の編集（TXTだけでOK）

[`site/pieces.txt`](site/pieces.txt) を編集すると、駒ごとの**レア度・HP・防御力・攻撃力・移動方法・移動距離・特殊効果・表示文字・説明**が変更できます。`site/data.js` のプログラムを編集する必要はありません。

```txt
# 名前,レア度,HP,防御力,攻撃力,移動方法,移動距離,特殊効果,表示文字,説明
爆弾魔,レア,5,1,2,縦横,2,爆弾,爆,攻撃した敵に爆弾を設置する。
寄生虫,レア,4,0,2,斜め,2,寄生,寄,倒した敵を味方に変える。
敵,レア,5,2,2,隣接,1,接近阻止,敵,移動後に敵の接近を防ぐ。
```

| 項目 | 設定できる値 |
| --- | --- |
| レア度 | `コモン` / `レア` / `レジェンダリー` |
| HP | `1〜9999` |
| 防御力・攻撃力 | `0〜9999` |
| 移動方法 | `隣接` / `歩兵` / `跳躍` / `縦横` / `斜め` / `全方向` |
| 移動距離 | `1〜8`（`跳躍` と `隣接` は `1` のみ） |
| 特殊効果 | `なし` / `爆弾` / `寄生` / `接近阻止` / `効果無効` / `処刑` |

すでにある32種類の駒は残してください。新しい漢字名の駒を追加することもできます。特殊効果は用意された6種類から選べ、TXTに任意のプログラムを書いて実行する方式ではありません。

ゲーム画面に駒性能の編集機能はありません。GitHubのTXTを編集して公開すると、全プレイヤー向けにその設定が反映されます。

## 保存

ゲームの進行状態はブラウザの `localStorage` に自動保存されます。同じブラウザで続きを遊べますが、別端末間の同期はありません。ステージと駒性能の設定はサーバー上のTXTから読み込むため、プレイヤー側で変更できません。

## Renderへの公開

- **Static Site** でGitHubの本リポジトリを選択。
- **Build Command:** `echo ready`
- **Publish Directory:** `site`
- APIキー・データベース・Node.jsサーバー不要。
